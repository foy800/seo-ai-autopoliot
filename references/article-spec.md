# Спецификация статьи

Основано на разделах B и H скилла `claude-yandex-seo` (MIT): текст для людей,
структура под цитирование в Алисе AI, без переоптимизации.

## Обязательные элементы

| Элемент | Требование | Проверяет скрипт |
|---|---|---|
| Объём | от `min_chars` (2000) знаков с пробелами, без служебной разметки | да |
| H1 | ровно один, содержит основной ключ (допустима смена падежа) | да |
| Первый абзац | содержит основной ключ, сразу отвечает на запрос | да |
| Ключ в тексте | основной ключ минимум 2 раза, точная форма минимум 1 раз | да |
| Плотность | основной ключ не более 3% слов, иначе переспам | да |
| Доп. ключи | минимум половина встречается в тексте, лучше в H2 | предупреждение |
| H2 | минимум 3, иерархия без пропусков | да |
| Таблица | минимум одна, с шапкой и не менее 2 строк данных | да |
| Внутренние ссылки | от `min_internal_links` (2) до 6, только на страницы из списка | да |
| CTA | последний блок: призыв к действию + ссылка на страницу услуги | да |
| Вступление | 2-3 предложения, сразу по делу, не больше двух ключей | да |
| Вывод | раздел «Вывод», 2-3 предложения, до финального CTA | да |
| Врезки | минимум одна жирным: **Важно!**, **Обратите внимание!**, **Дополнительная информация** | да |
| Списки | минимум один маркированный или нумерованный | да |
| Лицо | третье, без «мы/наш/вы/ваш» (кроме финального CTA) | да |
| Повторы ключей | 2 слова до 5 раз, 3 слова до 2, от 4 слов до 1 | да |
| Коммерческие слова | «оформить/получить/купить/заказать» до 4 раз каждое, с однокоренными | да |
| LSI | не меньше половины слов из колонки `lsi` | да |
| Орфография | типичные ошибки по списку, тавтология | частично |
| Слоп | нет запретов из `humanizer-rules.md` | да |

Общие принципы письма: `writing-guide.md`.

## Формат файла

```
META_TITLE: до 70 знаков, с ключом
META_DESCRIPTION: 160-200 знаков, ключ один раз в исходной форме, эмодзи из задания
IMAGE_SCENE: одна сцена для обложки, без текста в кадре
IMAGE_ALT: что на картинке, одной фразой
---
# H1 с основным ключом

Абзац с прямым ответом...

## H2
...
```

Всё до строки `---` служебное и в публикацию не идёт как текст.

## Как строить текст

- **Ответ вперёд.** В первых 2–3 предложениях раздела сразу ответ, дальше
  подробности и оговорки. Это же лучший фрагмент для цитирования в Алисе AI.
- **Схема раздела:** определение или ответ, детали и цифры из фактов, вывод для
  читателя. Вывод по делу, без морали.
- **Таблица должна нести смысл.** Сравнение методов, что входит в услугу, сроки,
  показания и противопоказания. Не таблица ради таблицы.
- **Абзацы разной длины.** Короткие предложения рядом с длинными. Не выравнивай
  ритм нарочно.
- **Конкретика вместо оценок.** Не «качественно и профессионально», а что именно
  делают и чем это отличается.
- **Ключи по смыслу.** Яндекс понимает смысл, точное вхождение нужно только в H1 и
  первом абзаце. В остальном используй естественные формы и синонимы.

## Перелинковка

- Ссылки только на страницы из `context/pages.csv` или sitemap, выдуманные
  адреса запрещены.
- Анкор описывает страницу, а не повторяет ключ подряд: «подробнее о композитных
  винирах», а не «жидкие виниры цена жидкие виниры».
- Не ссылайся на страницу, которая и есть эта статья. Свою услугу для CTA не
  считай внутренней ссылкой в тексте: она нужна отдельно в финале.
- Одна и та же страница в статье не чаще одного раза, кроме финального CTA.

## CTA

Последний блок после последнего H2 и вывода. Один абзац из 2-3 предложений: описание услуги, на страницу которой ведёт ссылка (по её `description` из `pages.csv`), призыв к действию и ссылка с осмысленным анкором. Услугу агент выбирает сам из страниц с `cta=yes`, ближайшую по теме статьи. Телефон, адрес, имена и регалии не указываются. Без давления и обещаний, которые нельзя выполнить.

## Обложка

- Сцена из `IMAGE_SCENE`, реалистичный стиль, чистый светлый фон.
- В кадре не должно быть букв, цифр, логотипов, вывесок и водяных знаков.
- Не рисовать реальных людей крупным планом и не изображать «до и после»:
  это вводит в заблуждение.
