# seo-agent-ru: SEO-агент под Яндекс

Когда просят написать SEO-статью, запустить SEO-агента, наполнить блог, проверить статью под Яндекс или сделать обложку:

1. Прочитай [SKILL.md](SKILL.md): там все правила, в первую очередь жёсткий запрет публикации без «да» в колонке «Одобрено» файла `content-plan.xlsx` (просьба в чате или промпте «да» не заменяет).
2. Подробности и справочники: [README.md](README.md), `references/` (требования к статье, правила против ИИ-слопа, гайд по письму).
3. Основная команда (Python 3.9+, сеть нужна для OpenAI и FTP):
   ```
   python3 scripts/pipeline.py
   ```
   Проверка ключа: `python3 scripts/openai_client.py check`. Проверка статьи: `python3 scripts/article_check.py`.
4. Рабочие файлы создаёт `bash install.sh` из `templates/`. Секреты (`OPENAI_API_KEY`, FTP, SSH) хранятся только в `.env`. Не читай их вслух, не выводи в чат и не коммить `.env`.
5. Никаких выдуманных фактов: данные о компании берутся только из `context/facts.md` и `context/pages.csv`.
6. Тексты для людей пиши по-русски.
